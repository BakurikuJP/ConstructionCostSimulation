# 建築コストシミュレーションの価格設定根拠

## 基本方針

- Minecraft の 1 ブロックは 1m x 1m x 1m とみなし、1 ブロック = 1m3 として扱う。
- 内部計算用のスコアボードは 1m3 あたりの円単位で保持する。
- 画面表示では数値が大きくなりすぎるため、千円単位のスコアボードも併用する。
- このアドオンは教育・ワークショップ向けの概算シミュレーションであり、実際の見積ではなく材料費の相対感を学ぶための値とする。
- 施工費、運搬費、型枠、鉄筋、廃材処分、地域差、時期差は含めない。
- すべての設置ブロックに価格を付けるため、明示単価のないブロックは素材名からカテゴリ判定し、判定が難しいものは `その他` として 10,000 円/m3 を計上する。

## 参照した公開情報

- 建設物価調査会の記事では、2023 年時点の都道府県庁所在地におけるレディーミクストコンクリートのベース価格平均が 18,940 円/m3 と説明されている。
  - https://www.kensetu-bukka.or.jp/article/12714/
- 建通新聞の 2025 年 5 月の記事スニペットでは、東京の生コンクリート 21-18-20 が 24,050 円/m3 どころとされている。
  - https://digital.kentsu.co.jp/articles/artcl_rglr/01JW7NWVGHFQH2QKN0G9YCBNKF
- 東京都財務局の工事設計単価表ページは、市場の実勢取引価格をもとに東京都が設計材料単価を設定していることを説明している。
  - https://www.zaimu.metro.tokyo.lg.jp/kenchiku/eizen/eizen-tanka/
- BuildApp News の 2026 年記事スニペットでは、東京の普通コンクリート民間実勢価格が概ね 21,000 から 24,000 円/m3 のレンジと説明されている。
  - https://news.build-app.jp/article/39439/

## ブロック別・カテゴリ別の設定

| Minecraft ブロック | アドオン上の想定 | 単価(円/m3) | 根拠・丸め方 |
| --- | --- | ---: | --- |
| 各色の concrete | 普通コンクリート | 24,050 | 2025 年東京の生コンクリート価格例をそのまま採用。1 ブロックを 1m3 として、ユーザー要望の「コンクリートブロック設置で 1m3 の価格を計上」に対応。 |
| 各色の concrete_powder | 未打設のコンクリート材料 | 18,000 | 生コンより安い材料段階として、2023 年平均 18,940 円/m3 を下回る概算値に丸めた。 |
| stone | 石材・砕石を用いた一般基礎材 | 8,000 | コンクリートより低単価の汎用石材としてゲーム内バランス用に設定。 |
| cobblestone | 粗い石材 | 6,500 | 加工度が低い石材として stone より低く設定。 |
| stone_bricks | 加工石材 | 12,000 | 加工費を含む石材として stone より高く設定。 |
| bricks | レンガ積み材料 | 35,000 | 焼成・成形された小割材料で、施工前材料としてコンクリートより高めに設定。 |
| glass | 板ガラス相当 | 12,000 | 建築の透明材料として、コンクリートより低めだが石材より高めに設定。 |
| 各種 planks | 構造・内装木材 | 60,000 | 現実の製材価格は幅が大きいが、ゲーム内で扱いやすい相対感を優先し、コンクリートより高すぎない教育用概算値に調整。 |
| bamboo_planks | 竹材 | 40,000 | 木材より軽量・低価格な代替材として、planks より低く設定。 |
| iron_block | 鉄骨・鋼材相当 | 150,000 | Minecraft の鉄ブロックは現実の純鉄塊に近すぎるため、建築用鋼材 1m3 相当の教育用概算として高額に設定。 |
| copper_block | 銅材相当 | 130,000 | 建築では屋根・配管・意匠材のイメージで、鋼材に近い高額材料として設定。 |
| diamond_block / gold_block / emerald_block | 高価装飾材 | 300,000 | Minecraft 上では希少・装飾性が高い材料のため、実建築材料ではなく展示用の高額仕上げ材として扱う。 |

## 自動分類ルール

明示単価がないブロックは、ブロック ID の名前から次のカテゴリに分類する。例えば `minecraft:oak_stairs` は木材、`minecraft:cut_sandstone` は石材、`minecraft:redstone_lamp` は設備または照明として計上される。

| カテゴリ | 判定例 | 単価(円/m3) | 考え方 |
| --- | --- | ---: | --- |
| コンクリート | `_concrete` | 24,050 | 明示設定と同じ。 |
| コンクリート粉末 | `_concrete_powder` | 18,000 | 未打設材料として低めに設定。 |
| 木材 | logs, wood, planks, stairs, slabs, fences, doors | 60,000 | 木材系の構造・内装材料。ゲーム内の資材感を優先して調整。 |
| 竹材 | bamboo を含むブロック | 40,000 | 木材より低価格の代替材。 |
| 石材・レンガ | stone, deepslate, granite, sandstone, brick, quartz など | 12,000 または 35,000 | 石材は 12,000 円、brick を含む加工・焼成材は 35,000 円。 |
| ガラス | glass を含むブロック | 12,000 | 透明建材として設定。 |
| 繊維・内装材 | wool, carpet | 25,000 | 仕上げ・内装材として設定。 |
| 焼成材 | terracotta, ceramic | 30,000 | タイル・陶板に近い仕上げ材として設定。 |
| 銅材 | copper | 130,000 | 屋根・配管・意匠金属として設定。 |
| 鉄・鋼材 | iron, chain, anvil | 150,000 | 構造金属として設定。 |
| 高価装飾材 | gold, diamond, emerald, netherite | 300,000 | ゲーム内の希少性を反映した展示用単価。 |
| 設備・機械部材 | redstone, rail, piston, observer, dispenser, dropper | 80,000 | 建築設備・機械部品として材料単価より高めに設定。 |
| 照明設備 | lantern, torch, lamp, light, glowstone | 45,000 | 電気・照明器具相当。 |
| 土砂・地盤材 | dirt, grass, sand, gravel, mud, clay | 3,000 | 造成・地盤材として低単価に設定。 |
| 植栽・自然材 | leaves, sapling, flower, moss, vine, coral | 5,000 | ランドスケープ用の自然材として設定。 |
| 氷雪材 | ice, snow | 4,000 | 特殊だが建築材料としては低単価に設定。 |
| その他 | 上記に該当しないすべてのブロック | 10,000 | 値付けが難しいブロックの漏れ防止用。 |

## スコアボード

| Objective ID | 表示名 | 内容 |
| --- | --- | --- |
| `BuildCost` | 建築コスト合計 | 対象ブロックを設置するたびに単価を加算した累計金額。円単位の内部記録。 |
| `BuildCostK` | 建築コスト合計(千円) | `BuildCost` を千円単位に丸めた表示用スコア。家規模の建築ではこちらを見る。 |
| `BuildLast` | 直近ブロック単価 | 最後に計上されたブロックの 1m3 単価。円単位の内部記録。 |
| `BuildLastK` | 直近ブロック単価(千円) | `BuildLast` を千円単位に丸めた表示用スコア。 |
| `BuildBlocks` | 建築ブロック数 | 計上されたブロックの設置数。 |

## ファイル構成と調整方針

- 単価そのものは `scripts/config/costCatalog.js` に集約する。
- 個別ブロックの上書きは `scripts/config/explicitBlockCosts.js` に追加する。
- ブロック ID からのカテゴリ判定は `scripts/config/blockCategoryMatcher.js` に閉じ込める。
- 外部から使う公開 API は `scripts/config/blockCosts.js` の `getBlockCost()` に限定する。
- 実際のイベント開催地に合わせる場合は、主に `scripts/config/costCatalog.js` の単価だけを差し替える。
- 施工費込みの総工費を扱う場合は、材料費に一律係数を掛けるのではなく、別のスコアボードとして「施工費」「材料費」を分ける。
- ブロック破壊時の減額は、今回は「設置したら計上」という要件を優先して未実装。現在の建物価値を表したい場合は、破壊イベントで差し引く Objective を別に追加する。
